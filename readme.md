# Финансовый трекер и каталог товаров

Консольное приложение на Python для управления каталогом товаров и категориями

## Описание функционала

- **Класс `Product`**: Управляет сущностью товара (название, описание, цена, количество на складе)
- **Класс `Category`**: Группирует товары по категориям, хранит список объектов `Product`
- **Глобальный подсчет**: Автоматически считает общее количество созданных категорий и уникальных товаров во всем каталоге при помощи атрибутов класса
- **Модуль `utils`**: Отвечает за чтение данных из внешних файлов `JSON` и автоматическую сборку дерева объектов

## Тестирование и линтинг

Для запуска автоматических тестов `pytest` выполните:
```bash
pytest
```

Для генерации HTML-отчета о покрытии кода тестами:
```bash
pytest --cov=src --cov-report=html
```
Результаты будут доступны в файле `htmlcov/index.html`.

Для проверки кода на соответствие стандартам PEP 8 используйте:
```bash
flake8 .
```
