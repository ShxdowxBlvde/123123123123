# Финансовый трекер и каталог товаров

Консольное приложение на Python для управления каталогом товаров и категориями

### 1. Класс `Product` (Товары)
* **Инкапсуляция цены**: Атрибут цены (`__price`) скрыт в приватном режиме для защиты от случайного изменения извне
* **Геттер и Сеттер цены (`@property`)**: Доступ к стоимости реализован через безопасный интерфейс. Сеттер выполняет строгую валидацию данных: если новая цена ниже или равна нулю, система блокирует операцию и выводит предупреждение в консоль
* **Фабричный класс-метод (`@classmethod`)**: Реализован альтернативный конструктор `new_product()`, который принимает на вход параметры в виде стандартного словаря (`dict`) и возвращает готовый объект класса `Product`

### 2. Класс `Category` (Категории)
* **Приватный список товаров**: Прямой доступ к списку продуктов (`__products`) закрыт извне
* **Контролируемое добавление**: Новые товары добавляются исключительно через метод `add_product(product)`. Это гарантирует строгий учет глобальных счетчиков
* **Форматированный геттер**: Метод-геттер `products` собирает данные обо всех вложенных товарах и возвращает их в виде единой строки, оформленной строго по заданному шаблону: `Название продукта, X руб. Остаток: X шт.\n`
* **Автоматические счетчики**: Класс динамически ведет сквозной учет общего количества созданных категорий и уникальных товаров в системе

## Тестирование и линтинг

Для запуска автоматических тестов `pytest` выполните:
```bash
pytest
```

Для генерации HTML-отчета о покрытии кода тестами:
```bash
pytest --cov=src --cov-report=html
```
Результаты будут доступны в файле `htmlcov/index.html`.

Для проверки кода на соответствие стандартам PEP 8 используйте:
```bash
flake8 .
```
